# Puzzle Combats

Приложение на **Kotlin + Jetpack Compose** для подготовки к чемпионату «Профессионалы»: соревнования двух игроков в пазлах Image и Circle. Реализуется по предоставленному конкурсному заданию 2026 года и копии Figma `Sprint-3`; состав задания марта 2027 года отдельно не подтверждён.

## Запуск

Требуется Android **14 / API 34** или новее. Откройте эту папку в Android Studio. Для сборки используются AGP 9.4.1, Gradle 9.6.0, Kotlin 2.2.10, Compose BOM 2026.02.01, JDK 21+ и Android SDK platform 37.0 / Build Tools 36.0.0. Встроенный JDK Android Studio подходит.

1. Укажите SDK в `local.properties` (`sdk.dir=...`) либо через Android Studio.
2. Скопируйте `secrets.properties.example` в `secrets.properties`, добавьте URL проекта и **publishable** ключ Supabase. Service-role/secret ключ в приложение добавлять нельзя.
3. Примените `backend/schema.sql` к выбранному проекту Supabase. В рабочем проекте `gamee` схема уже применена; существующие таблицы другого приложения не изменялись.
4. Запустите конфигурацию `app` на устройстве/эмуляторе.

На этом компьютере настройки `gamee` уже записаны в локальный игнорируемый `secrets.properties`. Регистрация в `gamee` требует подтверждения email; интерфейс сообщает об этом. По ТЗ допускаются только адреса вида `name123@domain123.ru`.

Windows PowerShell:

```powershell
.\tools\build.ps1 -WithLint
```

Linux/macOS:

```bash
./gradlew :app:assembleDebug :storybook:assembleDebug :domain:test :network:test :app:testDebugUnitTest :app:lintDebug
```

APK находятся в `app/build/outputs/apk/debug/` и `storybook/build/outputs/apk/debug/`. PowerShell-скрипт также копирует их в `artifacts/`. Локально дополнительно подготовлен компактный `artifacts/puzzle-combats-preview.apk`: оптимизированная release-сборка, подписанная стандартным debug-ключом только для установки и проверки. Для магазина требуется собственная защищённая подпись автора.

Если используется Windows/JBR 25 и путь содержит кириллицу, `tools/windows-test-paths.gradle` обходит ошибку декодирования JVM classpath, копируя только скомпилированные классы тестов и зависимости в временный ASCII-каталог. Исходники остаются в проекте.

## Состав

| Каталог | Назначение |
| --- | --- |
| `app/.../presentation` | Compose-экраны и ViewModel: авторизация, игры, профиль, статистика |
| `domain` | Чистые Kotlin-модели, интерфейс репозитория, правила пазлов и сценарии |
| `app/.../data` | Supabase-репозиторий, маппинг данных, защищённое хранение сессии |
| `libraries/network` | Самостоятельный JVM Gradle-проект, абстракция HTTP, REST DTO, обработка ошибок, API-тесты |
| `libraries/uikit` | Самостоятельный Android Gradle-проект, тема Poppins, компоненты и состояния |
| `storybook` | Отдельное Android-приложение для просмотра UIKit |
| `backend` | Схема PostgreSQL, RLS, атомарные игровые операции и серверные проверки |

Обе библиотеки имеют отдельные Gradle settings, версии `1.0.0` и Maven-публикации. Основное приложение подключает их через composite builds. Их исходники пока сохраняются в одном предоставленном GitHub-репозитории; требование конкурса о независимых Git-репозиториях библиотек отмечено в release checklist.

## Правила учебной реализации

- Image: сдвиговый пазл 3×3 с общей случайной seed на матч. Начальное поле гарантированно решаемое. Сервер проверяет последовательность ходов.
- Circle: пять кругов, выбор от большего к меньшему. Сервер проверяет итоговую последовательность.
- Начало и завершение фиксирует сервер. Первая корректная завершённая последовательность определяет победителя; повторный запрос не начисляет баллы повторно.
- Уход из активной игры — поражение. Незавершённый выход повторно синхронизируется после запуска. Heartbeat позволяет обнаружить отключившегося игрока при следующем запросе к матчу.
- Неделя статистики начинается в понедельник, часовой пояс — Europe/Moscow. `Played Games` означает победы, как в ТЗ.
- Пароль не сохраняется. Токены сессии зашифрованы Android Keystore; поля форм и последний экран сохраняются отдельно.
- Медиа кэшируются на диске. Напоминания планируются за час до начала; Android может сдвигать доставку в режиме энергосбережжения.

Сетка Image, жесты Circle, правило равенства по серверному времени и часовой пояс — явно выбранные правила для частей, которых нет в предоставленном прототипе.

## Дизайн и границы готовности

Иллюстрации, SVG и Poppins скачаны из предоставленного макета. Страницы Sprint-4/5 отсутствуют в этой копии Figma: Discover, Player, Statistics и игровые экраны оформлены в том же стиле без заявления о точном совпадении. Получение отдельного Success-экрана остановил лимит Figma MCP; для него использована доступная структура.

Социальный вход, восстановление пароля и переписка не входят в перечисленные 11 операций ТЗ. Их реальные сервисы не подключены; Chat открывает каталог игроков. Необходимые для публикации политика конфиденциальности и соглашение не приложены: добавьте окончательные PDF в `app/src/main/assets/legal/privacy.pdf` и `terms.pdf`. До этого интерфейс честно сообщает об отсутствии документов.

AppMetrica SDK интегрирован, события подключены; активация происходит только при заданном `APPMETRICA_API_KEY`. Для подтверждения работы в панели нужны ключ приложения и реальный прогон. Публикация в RuStore и создание подписи релиза не выполнялись.
