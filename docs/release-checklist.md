## Подготовка RuStore

По [официальной документации RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication) магазин принимает APK/AAB и требует уникальное имя пакета и подготовленную проверенную сборку. [Документация подписей](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/apk-signature) описывает цифровую подпись APK и отдельную загрузку подписи при AAB. Перед реальной сдачей проверить актуальные требования.

- [ ] Подтверждены владелец приложения, окончательный applicationId, название, versionCode/versionName.
- [ ] Создана release-сборка без debuggable и проверен R8/ProGuard на всех сценариях.
- [ ] APK/AAB подписан ключом владельца; сертификат проверен; ключ/пароль сохранены безопасно вне Git.
- [ ] Подготовлены иконка, реальные скриншоты, описание, контакты, категория и данные о разрешениях.
- [ ] Юридические ссылки и сведения о данных соответствуют фактическому поведению приложения.
- [ ] Проверены установка, обновление той же подписью, холодный запуск и восстановление данных.
- [ ] Владелец проверил конкретный пакет и материалы карточки перед отправкой.

Подготовка артефактов не означает публикацию: загрузка в аккаунт RuStore и отправка на модерацию остаются отдельным действием владельца.
