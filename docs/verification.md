# Проверка реализации

Проверяется на 30 сентября 2026 года. Фактические результаты ниже относятся к этой реализации предоставленного задания, а не к официальному набору карточек чемпионата: карточки не приложены. Доказательные снимки устройства хранятся локально в `docs/device-screenshots` и не включены в открытый репозиторий.

## Среда

- Windows, Android Studio JBR 25, Gradle 9.6.0, AGP 9.4.1.
- Компиляция Android API 37.0, минимальная ОС API 34.
- Созданный для проверки эмулятор AOSP Android 14/API 34 x86_64, WHPX, SwiftShader; 375×812 dp.
- Supabase `gamee`: схема `contest_*`, исходные таблицы проекта сохранены.

Серверный smoke проверяет успешные решения Image и Circle, запрет неверных/null ходов, сопоставимость перемешивания, атомарное место соперника, запрет чужого результата и прямого начисления очков, RLS, запрет раннего старта/досрочного forfeit, однократную победу, статистику, выход и истечение heartbeat. Проверка не отправляет письма.

Supabase Security Advisor не сообщил замечаний к добавленным объектам. Единственное INFO относится к прежней таблице `public.game_moves`, где RLS включён без политик. Таблица не используется приложением и не изменялась. [Описание проверки Supabase](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy).

## Ограничения проверки

Фактическая регистрация двух людей, переход по ссылке подтверждения email и игра между двумя физическими устройствами ещё не выполнены. Auth проверен на уровне HTTP-контракта, серверная игровая логика — с изолированными SQL fixtures. UI-тесты с тестовым репозиторием не являются подтверждением полного сетевого E2E.

Не проверены реальные камера/галерея телефона, доставка напоминания под ограничениями конкретного производителя, AppMetrica Dashboard без ключа и публикация в RuStore. Для продолжения есть [ручной план](manual-test-plan.md).

Полного макета Sprint-4/5 нет. Нельзя подтвердить точное соответствие игровых экранов отсутствующему прототипу. Размеры текста с увеличенным системным масштабом и компактные экраны используют прокрутку/адаптивный вариант; исходная Figma содержит только базовый портретный размер.

Компактный установочный `puzzle-combats-preview.apk` подписан стандартным локальным debug-ключом; v3-подпись проверена `apksigner verify`. Размер 4 634 159 байт; SHA-256: `B2F6CD071F90E0687D84D223817E94955336576A712F189EF8507A3F54B6DB20`. Это сборка для проверки, не магазинная подпись автора.

Исходники библиотек имеют независимые Gradle builds/версии/Maven publications, но пока один Git-репозиторий. Независимые удалённые Git-репозитории библиотек, официальные PDF, ключ AppMetrica и release-подпись отмечены в [release checklist](release-checklist.md).
